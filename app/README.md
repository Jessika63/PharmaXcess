# PharmaXcess Application

This folder contains the **web application** of PharmaXcess.

It is composed of two main parts:

- `web_server/` – the backend (server)
- `pharmaXcess_app/` – the frontend (client)

## Structure Overview
```sh
app/
├─ web_server/
├─ pharmaXcess_app/
```
